# 使用與動畫規格

## 如何開始

安裝完成後，開啟新的 Codex 對話，提供角色圖片並描述想做的動作。可以直接說：

> 使用 comfyui-forge-video2dsprite，將這張角色圖製作成朝右的原地跑步循環，輸出透明動畫與 GIF 預覽。

可指定方向、循環或單次播放、成品尺寸與播放長度。已有影片也可以交給 Codex 處理成透明角色動畫。

## 如何選擇規格

首次使用時，Codex 會先確認成品尺寸與播放長度，預設為 **128×128、1 秒**；你可以改成需要的規格。

成品以 **8 fps** 為初始值，Codex 會依動作在 **4–16 fps** 間評估，兼顧流暢度與影格數。需要超過 16 fps 時會先說明並取得同意，最高 24 fps；不熟悉 fps 也能使用。

來源影片提供三種解析度，依電腦效能與細節需求選擇，並確認工作流可支援：

| 選項 | 解析度 |
|---|---|
| 1. 效能 | 512×512 |
| 2. 平衡（預設） | 768×768 |
| 3. 品質 | 1024×1024 |

來源影片的解析度與長度和最終成品不同。Codex 會自動安排較長的來源影片，從完整動作中選出一組製作成品；每次生成前會列出當次成品與來源規格。同一對話可沿用已確認的設定。

## 製作過程

Codex 會先評估角色圖片是否適合指定動作；需要動作專用首圖時，會先展示新圖片供你確認。影片由本機 ComfyUI 生成，再進行去背、定位、選格與播放效果檢查。

若連續兩次生成出現相同偏差，Codex 會說明問題，讓你選擇調整條件或維持要求繼續嘗試。生成結果仍需檢查角色外觀、動作完整性與透明邊緣。

## 會收到什麼

完成後會提供 ZIP，包含：

- 選定的透明 PNG 影格。
- 透明 PNG 動畫圖集。
- GIF 預覽。
- 原始來源 MP4。

對話中也會展示預覽、圖集與來源影片，並標示成品尺寸、影格數、fps 與播放方式。圖集由左至右、由上至下讀取；不足 8 格使用單列，8 格以上使用雙列。

GIF 方便預覽，單次動作也可能重複播放；遊戲中的循環或單次播放方式以交付說明為準。GIF 的透明與時間精度有限，正式透明素材使用 PNG。

中間檔案與檢查紀錄留在另附連結的工作目錄。之後若只需調整取幀或播放節奏，可以請 Codex 優先沿用已有影片處理。
