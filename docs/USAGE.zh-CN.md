# 使用与动画规格

[繁體中文](USAGE.md) | **简体中文** | [English](USAGE.en.md) | [日本語](USAGE.ja.md) | [한국어](USAGE.ko.md)

## 如何开始

安装完成后，开启新的 Codex 对话，提供角色图片并描述想做的动作。可以直接说：

> 使用 comfyui-forge-video2dsprite，将这张角色图制作成朝右的原地跑步循环，输出透明动画与 GIF 预览。

可指定方向、循环或单次播放、成品尺寸与播放时长。已有视频也可以交给 Codex 处理成透明角色动画。

## 如何选择规格

首次使用时，Codex 会先确认成品尺寸与播放时长，默认为 **128×128、1 秒**；你可以改成需要的规格。

成品以 **8 fps** 为初始值，Codex 会依动作在 **4–16 fps** 间评估，兼顾流畅度与帧数。需要超过 16 fps 时会先说明并征得同意，最高 24 fps；不熟悉 fps 也能使用。

源视频提供三种分辨率，依电脑性能与细节需求选择，并确认工作流可支持：

| 选项 | 分辨率 |
|---|---|
| 1. 性能 | 512×512 |
| 2. 平衡（默认） | 768×768 |
| 3. 质量 | 1024×1024 |

源视频的分辨率与时长和最终成品不同。Codex 会自动安排较长的源视频，从完整动作中选出一组制作成品；每次生成前会列出当次成品与源视频规格。同一对话可沿用已确认的设置。

## 制作过程

Codex 会先评估角色图片是否适合指定动作；需要动作专用首图时，会先展示新图片供你确认。视频由本机 ComfyUI 生成，再进行去背、定位、选帧与播放效果检查。

如果连续两次生成出现相同偏差，Codex 会说明问题，让你选择调整条件或维持要求继续尝试。生成结果仍需检查角色外观、动作完整性与透明边缘。

## 会收到什么

完成后会提供 ZIP，包含：

- 选定的透明 PNG 帧。
- 透明 PNG 动画图集。
- GIF 预览。
- 原始源 MP4。

对话中也会展示预览、图集与源视频，并标明成品尺寸、帧数、fps 与播放方式。图集从左到右、从上到下读取；不足 8 帧使用单行，8 帧及以上使用双行。

GIF 方便预览，单次动作也可能重复播放；游戏中的循环或单次播放方式以交付说明为准。GIF 的透明与时间精度有限，正式透明素材使用 PNG。

中间文件与检查记录保留在另附链接的工作目录。之后如果只需调整选帧或播放节奏，可以请 Codex 优先沿用已有视频处理。
