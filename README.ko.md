# ComfyUI-Sprite-Forge

[繁體中文](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | **한국어** | [English](README.en.md)

**캐릭터 이미지를 게임용 투명 배경 애니메이션으로 만들고, 도구 조작은 Codex에 맡기세요.**

예를 들어 캐릭터 이미지를 주고 달리기 동작을 만든 뒤, 투명 PNG 스프라이트 시트와 GIF 미리보기를 출력할 수 있습니다. 영상은 **내 컴퓨터의 ComfyUI**에서 생성하므로 클라우드 생성용 API 키가 필요하지 않습니다.

이 프로젝트는 **0x0funky**가 만든 [Agent Sprite Forge](https://github.com/0x0funky/agent-sprite-forge)의 **비공식 수정판**입니다. 원본의 [MIT 라이선스](LICENSE)를 유지합니다. 독립된 스킬 이름을 사용하므로 원본과 함께 설치할 수 있습니다.

## 먼저 준비할 것

1. **Codex**: 로컬 파일을 읽고 도구를 실행할 수 있어야 합니다.
2. **로컬 ComfyUI**: 설치되어 있고, **자신의 MiniMax H3 워크플로로 영상을 정상 생성할 수 있어야 합니다**.

모델은 포함되어 있지 않으며, ComfyUI도 대신 설치하지 않습니다. 그 밖의 소프트웨어 의존성은 Codex에 점검과 설치를 요청할 수 있습니다.

ComfyUI 워크플로는 포함되어 있지 않습니다. 영상 생성이 정상 작동하는 본인의 API JSON을 준비하세요.

### FFmpeg 설치（Windows）

이 스킬은 영상 처리를 위해 FFmpeg와 FFprobe가 필요합니다.

아직 설치하지 않았다면 다음 사이트에서 Windows 버전을 받을 수 있습니다.

`https://www.gyan.dev/ffmpeg/builds/`

설치 방법을 잘 모른다면 위 URL을 Codex에 전달하고 설치, PATH 설정, FFmpeg와 FFprobe의 정상 실행 확인을 요청하세요.

이미 설치되어 있다면 다시 설치할 필요가 없습니다.

## 설치 방법

아래 내용을 자신의 Codex에 붙여 넣으세요.

> https://github.com/yuwechang/ComfyUI-Sprite-Forge 에서 comfyui-sprite-forge를 설치해 주세요. 저장소의 설치 안내에 따라 모든 스킬을 설치하고, 원본 Sprite Forge와 다른 스킬은 변경하지 마세요. 제 로컬 ComfyUI에서는 H3가 이미 작동합니다. 제 워크플로 설정과 호환성 확인을 도와주세요. 필요한 파일 위치는 질문해 주세요. 모델을 자동으로 다운로드하거나 영상 생성을 시작하지 마세요.

설치가 끝나면 **새 Codex 대화를 열어** 사용하세요.

## 내 워크플로를 사용할 수 있나요?

네. ComfyUI에서 **API 형식의 JSON 파일**로 내보낸 다음, 파일을 Codex에 주고 이렇게 요청하세요.

> ComfyUI-Sprite-Forge가 이 워크플로를 사용하도록 설정하고 호환성을 확인해 주세요.

Codex는 프로젝트 안내에 따라 필요한 노드를 확인합니다. 워크플로에 따라 조정이 필요할 수 있습니다. 내보내는 방법을 모르면 먼저 Codex에 안내를 요청하세요.

## 애니메이션 만드는 방법

캐릭터 이미지를 첨부하고 Codex에 이렇게 말하세요.

> comfyui-forge-video2dsprite를 사용해 이 캐릭터가 오른쪽을 바라보며 제자리에서 달리는 루프를 만들어 주세요. 게임 재생 시간은 1초, 크기는 128×128, 속도는 8 fps인 투명 배경 애니메이션으로 출력하고 GIF 미리보기도 주세요. 카메라는 고정하고 효과는 추가하지 마세요.

기본적으로 약 **3초**의 원본 영상을 생성한 뒤 적절한 동작 프레임을 고릅니다. 위 예시는 **8프레임을 각각 0.125초씩, 총 1초** 동안 재생합니다.

캐릭터의 비율을 유지해 축소한 후 투명 캔버스에 배치합니다. 영상 전체를 정사각형으로 늘이거나 압축하지 않습니다. 생성 결과의 외형, 동작, 배경 제거 품질은 직접 확인해야 합니다.

## 첫 사용 설정 및 결과물

처음에는 최종128×128·1초·8fps, 원본영상640×640·요청3초·24fps를 사용할지 묻습니다. 변경 시 최종 규격에 따라 계산한 성능／균형／품질 또는 사용자 지정 원본 설정을 선택합니다. 확정한 설정은 로컬 프로젝트에 저장하고 다음 사용 시 재사용 여부를 확인합니다. 안내는 대화 언어에 맞춥니다.

긴 원본은 여러 완성 동작 중 하나를 고르기 위한 것이며 최종 애니메이션이3초이거나3번 반복된다는 뜻이 아닙니다. 기본ZIP에는 선택된PNG프레임, 투명 애니메이션 시트, GIF와 원본영상만 포함합니다. JSON·로그·보고서는 링크된 작업 폴더에 남깁니다.
