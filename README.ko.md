# ComfyUI-Sprite-Forge

[繁體中文](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | **한국어** | [English](README.en.md)

**캐릭터 이미지를 게임용 투명 배경 애니메이션으로 만들고, 도구 조작은 Codex에 맡기세요.**

예를 들어 캐릭터 이미지를 주고 달리기 동작을 만든 뒤, 투명 PNG 스프라이트 시트와 GIF 미리보기를 출력할 수 있습니다. 영상은 **내 컴퓨터의 ComfyUI**에서 생성하므로 클라우드 생성용 API 키가 필요하지 않습니다.

이 프로젝트는 [Agent Sprite Forge](https://github.com/0x0funky/agent-sprite-forge)를 기반으로 한 **비공식 수정판**으로, video2sprite 캐릭터 애니메이션 제작 흐름에 집중합니다. 영상 생성은 **로컬에서 실행되는 ComfyUI에만** 연결합니다. 클라우드 API와 로컬 CLI 생성 서비스 호출을 모두 제거하고, 투명 배경 캐릭터 애니메이션 제작에 필요한 전처리와 후처리 기능은 유지했습니다. 또한 사양 설정, 동작과 구도 평가, 생성 결과 검수, 재시도 판단, 프레임 선택과 타이밍 조정을 개선하여 제작 과정을 더 명확하게 파악하고 제어할 수 있도록 했습니다.

이 수정판에는 원본의 **generate2dmap, codeart2d** 스킬이 포함되지 않으며, 그 밖의 독립적인 에셋 생성이나 클라우드 영상 생성 서비스도 제공하지 않습니다. 지도, 코드 기반 그림, 클라우드 API를 통한 영상 생성 등이 필요하면 원본 **Agent Sprite Forge**를 별도로 설치하세요. 두 버전은 스킬 이름, 디렉터리, 설치 기록이 독립되어 함께 설치할 수 있습니다. 각 버전은 자체 프로그램만 사용하며 서로 덮어쓰거나, 간섭하거나, 호출하지 않습니다.

원작자는 **0x0funky**이며, 이 프로젝트는 원본의 [MIT 라이선스](LICENSE)를 유지합니다.

## 먼저 준비할 것

1. **Codex**: 로컬 파일을 읽고 도구를 실행할 수 있어야 합니다.
2. **로컬 ComfyUI(영상 생성 시)**: 설치되어 있고, **자신의 MiniMax H3 워크플로로 영상을 정상 생성할 수 있어야 합니다**.

모델은 포함되어 있지 않으며, ComfyUI도 대신 설치하지 않습니다. 그 밖의 소프트웨어 의존성은 Codex에 점검과 설치를 요청할 수 있습니다.

ComfyUI 워크플로는 포함되어 있지 않습니다. 영상 생성이 정상 작동하는 본인의 API JSON을 준비하세요.

## FFmpeg 설치（Windows）

이 스킬은 영상 처리를 위해 FFmpeg와 FFprobe가 필요합니다. 아래 문장을 Codex에 붙여넣으세요:

> 내 Windows 컴퓨터에 FFmpeg와 FFprobe가 설치되어 정상적으로 실행되는지 확인하고, 설치되지 않은 도구는 https://www.gyan.dev/ffmpeg/builds/ 에서 다운로드하여 설치하고 PATH를 설정한 뒤 두 도구가 모두 정상적으로 실행되는지 확인해 주세요(이미 설치된 도구는 다시 설치할 필요가 없습니다).

## 이 Skill 설치 방법

아래 내용을 자신의 Codex에 붙여 넣으세요.

> https://github.com/yuwechang/ComfyUI-Sprite-Forge 에서 comfyui-sprite-forge를 설치해 주세요. 저장소의 설치 안내에 따라 모든 스킬을 설치해 주세요. 제 로컬 ComfyUI에서는 H3가 이미 작동합니다. 제 워크플로 설정과 호환성 확인을 도와주세요. 필요한 파일 위치는 질문해 주세요. 모델을 자동으로 다운로드하거나 영상 생성을 시작하지 마세요.

설치가 끝나면 **새 Codex 대화를 열어** 사용하세요.

## 내 워크플로를 사용할 수 있나요?

네. ComfyUI에서 **API 형식의 JSON 파일**로 내보낸 다음, 파일을 Codex에 주고 이렇게 요청하세요.

> ComfyUI-Sprite-Forge가 이 워크플로를 사용하도록 설정하고 호환성을 확인해 주세요.

Codex는 프로젝트 안내에 따라 필요한 노드를 확인합니다. 워크플로에 따라 조정이 필요할 수 있습니다. 내보내는 방법을 모르면 먼저 Codex에 안내를 요청하세요.

## 애니메이션 만드는 방법

캐릭터 이미지를 첨부하고 Codex에 이렇게 말하세요.

> comfyui-forge-video2dsprite를 사용해 이 캐릭터가 오른쪽을 바라보며 제자리에서 달리는 루프를 만들어 주세요.

기존 영상을 제공해 투명 캐릭터 애니메이션으로 변환할 수도 있습니다. 이 경우 원본 영상 생성은 필요하지 않습니다.

## 첫 사용 설정 및 결과물

처음에는 최종 셀 크기와 재생 시간(기본128×128,1초)을 확인하며 fps 입력은 요구하지 않습니다. 출력은8fps에서 시작해4-16fps로 평가하고,16초과는 이유를 설명한 뒤 별도 동의를 받습니다(최대24fps). 원본 해상도만 번호로 선택합니다:1 성능512×512,2 균형768×768(기본),3 품질1024×1024. 원본은24fps 고정이며 길이는 최종 재생 시간의2-3배로 자동 평가하고 프레임 정렬 후에도15초를 넘지 않습니다. 같은 대화에서 설정을 재사용할 수 있지만 생성 전마다 현재 최종/원본 사양을 표시합니다. 안내는 대화 언어에 맞춥니다.

원본 영상은 비교할 수 있는 완전한 동작 2–3회를 목표로 하지만, 완전하고 적합한 후보가 하나면 충분합니다. 최종 애니메이션에는 그중 하나만 사용합니다. 기본ZIP에는 선택된PNG프레임, 투명 애니메이션 시트, GIF와 원본영상만 포함합니다. JSON·로그·보고서는 링크된 작업 폴더에 남깁니다.
