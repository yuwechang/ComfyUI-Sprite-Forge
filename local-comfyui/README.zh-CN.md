# 本机 ComfyUI 配置文件

[繁體中文](README.md) | **简体中文** | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

本目录的配置文件用途：

- `config.example.json`：配置模板。
- `config.local.json`：根据模板创建，填写本机 ComfyUI 地址、工作流路径与节点映射。
- `workflow.local.json`：可选的工作流存放位置，也可在配置中指定其他路径。

相对工作流路径以配置文件所在文件夹解析。详细步骤见 [工作流配置](../docs/WORKFLOW.zh-CN.md)。
