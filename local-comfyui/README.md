# 本機 ComfyUI 設定檔

**繁體中文** | [简体中文](README.zh-CN.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

本目錄的設定檔用途：

- `config.example.json`：設定範本。
- `config.local.json`：依範本建立，填入本機 ComfyUI 位址、工作流路徑與節點對應。
- `workflow.local.json`：可選的工作流存放位置，也可在設定中指定其他路徑。

相對工作流路徑以設定檔所在資料夾解析。詳細步驟見 [工作流設定](../docs/WORKFLOW.md)。
