# Local ComfyUI configuration files

[繁體中文](README.md) | [简体中文](README.zh-CN.md) | **English** | [日本語](README.ja.md) | [한국어](README.ko.md)

Configuration files in this directory:

- `config.example.json`: configuration template.
- `config.local.json`: create from the template and fill in the local ComfyUI address, workflow path, and node bindings.
- `workflow.local.json`: optional workflow location; you can specify another path in the configuration.

Relative workflow paths resolve from the configuration directory. See [workflow configuration](../docs/WORKFLOW.en.md) for details.
