# 로컬 ComfyUI 설정 파일

[繁體中文](README.md) | [简体中文](README.zh-CN.md) | [English](README.en.md) | [日本語](README.ja.md) | **한국어**

이 폴더의 설정 파일:

- `config.example.json`: 설정 템플릿.
- `config.local.json`: 템플릿으로 만들고 로컬 ComfyUI 주소, 워크플로 경로 및 노드 연결을 설정합니다.
- `workflow.local.json`: 선택적인 워크플로 저장 위치. 설정에서 다른 경로를 지정할 수도 있습니다.

상대 워크플로 경로는 설정 파일 폴더 기준입니다. 자세한 내용은 [워크플로 설정](../docs/WORKFLOW.ko.md)을 참조하세요.
