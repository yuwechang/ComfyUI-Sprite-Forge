# ローカル ComfyUI の設定ファイル

[繁體中文](README.md) | [简体中文](README.zh-CN.md) | [English](README.en.md) | **日本語** | [한국어](README.ko.md)

このフォルダーの設定ファイル：

- `config.example.json`：設定テンプレート。
- `config.local.json`：テンプレートから作成し、ローカル ComfyUI のアドレス、ワークフローのパス、ノードの対応を設定します。
- `workflow.local.json`：任意のワークフロー保存先。設定で別のパスも指定できます。

相対パスは設定ファイルのフォルダーが基準です。詳細は [ワークフロー設定](../docs/WORKFLOW.ja.md) を参照してください。
