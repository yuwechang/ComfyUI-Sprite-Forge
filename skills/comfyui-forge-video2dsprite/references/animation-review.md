# Motion selection and acceptance

Assess the requested behavioral contract, not the motion label. cycle requires a complete moving period with pose and velocity continuity. oneshot-return requires a complete action and recovery to its initial pose; equal endpoint images do not imply continuous repetition. oneshot-hold requires the requested final state, retained without a fabricated recovery. Selection never crosses between source demonstrations or contains source-only resets.

Use comfyui_forge_gait_loop.py select --kind cycle --policy cycle for a proposed general period. Specialized feature analyses are optional diagnostics, never motion-name dispatch. Inspect phase completeness: a numeric seam alone cannot certify that the entire intended period is present. If automatic selection fails, review a forward interval rather than synthesizing reverse playback.

For either one-shot, use comfyui_forge_retime.py --kind TYPE --range START:END --auto-oneshot --duration-ms FINAL_MS --output-fps FINAL_FPS --output-dir NEW. The reviewed source interval is one complete candidate. Add --key NAME=SOURCE@PHASE[+HOLDms] and --event-source NAME=SOURCE only for actual requested timing needs. These controls support any motion; there are no built-in phase percentages or named-action durations. Direct --spans/--selection and --duration-ms/--ticks remain available for explicitly authored timing.

Finish all candidate frames at one fixed scale, then comfyui_forge_finalize_animation.py prepare with the selection and confirmed specification. The final review records source indices, authored timing, materialized slots, event mapping, quantization errors, omitted transitions, alpha bounds and cycle seam metrics. Review the actual final GIF and light/dark contact sheet. Intentional holds may repeat PNG poses; they must not be mistaken for new unique motion. Too few slots for required poses is an error. Approval requires complete action, correct final state, identity, framing, readable timing and clean transparency, not a numeric score alone.
