# ComfyUI-Sprite-Forge

[繁體中文](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | **English**

**Turn a character image into a transparent game animation, with Codex handling the tools.**

For example, give Codex a character image and ask for a running animation, a transparent PNG sprite sheet, and a GIF preview. Video is generated by **ComfyUI on your own computer**. No cloud generation API key is needed.

This project is an **unofficial fork** of [Agent Sprite Forge](https://github.com/0x0funky/agent-sprite-forge), focused on the video2sprite character-animation workflow. Video generation connects exclusively to **ComfyUI running locally**. All calls to cloud APIs and local CLI generation services have been removed, while the preprocessing and postprocessing needed to produce transparent character animations are retained. The workflow also improves specification setup, motion and framing assessment, generated-result review, retry decisions, and frame selection and timing, making production clearer and easier to control.

This fork does not include the original **generate2dmap** or **codeart2d** skills, nor does it provide other standalone asset-generation or cloud video-generation services. For maps, code-drawn art, or video generation through cloud APIs, install the original **Agent Sprite Forge** separately. The two use independent skill names, directories, and installation records and can be installed side by side. Each uses its own programs without overwriting, interfering with, or calling the other.

The original author is **0x0funky**. This project preserves the original [MIT license](LICENSE).

## What you need first

1. **Codex**, with access to local files and tools.
2. **Local ComfyUI**, already installed and **able to generate a video with your MiniMax H3 workflow**.

Models are not included, and this project does not install ComfyUI for you. You can ask Codex to check and install the other software dependencies.

No ComfyUI workflow is bundled. Bring your own API JSON that already generates videos successfully.

### FFmpeg installation (Windows)

This skill requires FFmpeg and FFprobe to process video.

If they are not installed yet, you can get a Windows build from:

`https://www.gyan.dev/ffmpeg/builds/`

If you are unfamiliar with the installation process, give the URL above to Codex and ask it to help install the tools, configure PATH, and verify that both FFmpeg and FFprobe run correctly.

If they are already installed, there is no need to install them again.

## How to install

Copy this message into your Codex:

> Install comfyui-sprite-forge from https://github.com/yuwechang/ComfyUI-Sprite-Forge . Follow the repository's installation instructions to install all skills, keeping the original Sprite Forge and my other skills unchanged. My local ComfyUI can already run H3. Help configure my workflow and check compatibility. Ask for file locations if needed. Do not automatically download models or start generating video.

After installation, **open a new Codex chat** before using the skills.

## Can I use my own workflow?

Yes. Export your workflow from ComfyUI as an **API-format JSON file**, give the file to Codex, and say:

> Configure ComfyUI-Sprite-Forge to use this workflow and check its compatibility.

Codex can follow the project instructions to identify the required nodes. Some workflows need adjustments. If you do not know how to export the file, ask Codex for guidance first.

## How to create an animation

Attach your character image and tell Codex:

> Use comfyui-forge-video2dsprite to create a right-facing run cycle in place from this character image. Export a transparent 128×128 animation at 8 fps, with a game playback length of 1 second, plus a GIF preview. Keep the camera fixed and add no effects.

By default, the tool requests about **3 seconds** of source video, then selects suitable motion frames. The example produces **8 frames, each displayed for 0.125 seconds, totaling 1 second**.

The character is scaled proportionally into a transparent canvas; the entire video is not stretched into a square. Check the result for character consistency, motion, and background-removal quality.

## First use and delivery

First use confirms final cell size and playback duration (defaults128×128 and1second), without asking for fps. Output starts at8fps and adapts within4-16; above16 requires separate approval, maximum24fps. Choose only source resolution by number:1 performance512×512,2 balanced768×768(default),3 quality1024×1024. Source runs at24fps; duration is automatically assessed at2-3 times final playback, capped at15seconds including cadence alignment. Same-chat tasks may reuse settings, but every generation displays the current final/source specification. Guidance follows your conversation language.

The longer source provides multiple complete action candidates to choose from; final playback does not automatically last 3 seconds or repeat 3 times. Standard delivery ZIP contains only selected PNG frames, a transparent animation sheet, GIF preview and source video. Previews appear in chat; JSON/logs/reports remain in the linked working directory.
