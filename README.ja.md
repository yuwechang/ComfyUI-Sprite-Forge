# ComfyUI-Sprite-Forge

[繁體中文](README.md) | [简体中文](README.zh-CN.md) | **日本語** | [한국어](README.ko.md) | [English](README.en.md)

**キャラクター画像を、ゲーム用の背景透過アニメーションに。操作は Codex に任せられます。**

たとえば、キャラクター画像を渡して走る動きを作り、透過 PNG スプライトシートと GIF プレビューを出力できます。動画は**自分のパソコンの ComfyUI** で生成します。クラウド生成用の API キーは不要です。

本プロジェクトは、**0x0funky** 氏による [Agent Sprite Forge](https://github.com/0x0funky/agent-sprite-forge) の**非公式フォーク**です。元の [MIT ライセンス](LICENSE) を保持しています。独自のスキル名を使うため、元の版と同時にインストールできます。

## 最初に必要なもの

1. **Codex**：ローカルファイルを読み、ツールを実行できること。
2. **ローカルの ComfyUI**：インストール済みで、**自分の MiniMax H3 ワークフローで動画を生成できること**。

モデルは付属していません。ComfyUI のインストールも行いません。その他のソフトウェア依存関係は、Codex に確認とインストールを依頼できます。

## インストール方法

次の文章を自分の Codex に貼り付けてください。

> https://github.com/yuwechang/ComfyUI-Sprite-Forge から comfyui-sprite-forge をインストールしてください。リポジトリの手順に従い、すべてのスキルをインストールしてください。元の Sprite Forge と他のスキルは変更しないでください。ローカルの ComfyUI では H3 がすでに動作しています。自分のワークフローの設定と互換性確認を手伝ってください。必要なファイルの場所は質問してください。モデルの自動ダウンロードや動画生成は始めないでください。

完了後は、**新しい Codex チャットを開いて**使用してください。

## 自分のワークフローは使えますか？

使えます。ComfyUI から **API 形式の JSON ファイル**として書き出し、そのファイルを Codex に渡して、次のように依頼します。

> このワークフローを ComfyUI-Sprite-Forge で使えるように設定し、互換性を確認してください。

Codex はプロジェクトの説明を読み、必要なノードを確認します。ワークフローによっては調整が必要です。書き出し方が分からなければ、先に Codex に手順を聞いてください。

## アニメーションの作り方

キャラクター画像を添付し、Codex に次のように伝えます。

> comfyui-forge-video2dsprite を使い、このキャラクターが右を向いて、その場で走るループを作ってください。ゲームでの再生時間は 1 秒、128×128、8 fps の背景透過アニメーションにし、GIF プレビューも付けてください。カメラは固定し、エフェクトは追加しないでください。

標準では約 **3 秒**の元動画を生成し、適切な動作フレームを選びます。この例では、**8 フレームを各 0.125 秒、合計 1 秒**で再生します。

キャラクターの縦横比を保って縮小し、透明なキャンバスに配置します。動画全体を正方形に引き伸ばすことはしません。生成後は見た目、動き、背景除去の品質を確認してください。
