# ComfyUI-Sprite-Forge

[繁體中文](README.md) | [简体中文](README.zh-CN.md) | **日本語** | [한국어](README.ko.md) | [English](README.en.md)

**キャラクター画像を、ゲーム用の背景透過アニメーションに。操作は Codex に任せられます。**

たとえば、キャラクター画像を渡して走る動きを作り、透過 PNG スプライトシートと GIF プレビューを出力できます。動画は**自分のパソコンの ComfyUI** で生成します。クラウド生成用の API キーは不要です。

本プロジェクトは [Agent Sprite Forge](https://github.com/0x0funky/agent-sprite-forge) を基にした**非公式の修正版**で、video2sprite のキャラクターアニメーション制作に特化しています。動画生成の接続先は**ローカルで動作する ComfyUI のみ**です。クラウド API とローカル CLI 型生成サービスへの呼び出しをすべて削除し、背景透過キャラクターアニメーションの制作に必要な前処理・後処理を維持しています。また、仕様設定、動作と構図の評価、生成結果の確認、再試行の判断、フレーム選択とタイミング調整を改善し、制作工程をより明確で制御しやすいものにしています。

本修正版には、原版の **generate2dmap、codeart2d** は含まれず、そのほかの独立した素材生成やクラウド動画生成サービスも提供しません。マップ、コードによる描画、クラウド API 経由の動画生成などが必要な場合は、原版の **Agent Sprite Forge** を別途インストールしてください。両者はスキル名、ディレクトリ、インストール記録が独立しており、同時にインストールできます。それぞれ自身のプログラムを使用し、互いのファイルを上書きしたり、動作を妨げたり、相互に呼び出したりしません。

原作者は **0x0funky** 氏です。本プロジェクトは原版の [MIT ライセンス](LICENSE) を保持しています。

## 使用前の準備

1. **Codex**：ローカルファイルを読み、ツールを実行できること。
2. **ローカルの ComfyUI（動画を生成する場合）**：インストール済みで、**自分の MiniMax H3 ワークフローで動画を生成できること**。

モデルは付属していません。ComfyUI のインストールも行いません。その他のソフトウェア依存関係は、Codex に確認とインストールを依頼できます。

ComfyUI のワークフローは同梱していません。動画を正常に生成できる、ご自身の API JSON を用意してください。

## FFmpeg のインストール（Windows）

このスキルでは、動画の処理に FFmpeg と FFprobe が必要です。次の一文を Codex に貼り付けてください：

> 私の Windows PC に FFmpeg と FFprobe がインストールされ、正常に実行できるか確認し、未インストールのツールは https://www.gyan.dev/ffmpeg/builds/ からダウンロードしてインストールと PATH の設定を行い、両方が正常に実行できることを確認してください（インストール済みのツールは再インストール不要です）。

## この Skill のインストール方法

次の文章を自分の Codex に貼り付けてください。

> https://github.com/yuwechang/ComfyUI-Sprite-Forge から comfyui-sprite-forge をインストールしてください。リポジトリの手順に従い、すべてのスキルをインストールしてください。ローカルの ComfyUI では H3 がすでに動作しています。自分のワークフローの設定と互換性確認を手伝ってください。今回はインストール、設定、確認のみを行い、モデルのダウンロードや動画生成は行わないでください。

完了後は、**新しい Codex チャットを開いて**使用してください。

## 自分のワークフローは使えますか？

使えます。ComfyUI から **API 形式の JSON ファイル**として書き出し、そのファイルを Codex に渡して、次のように依頼します。

> このワークフローを ComfyUI-Sprite-Forge で使えるように設定し、互換性を確認してください。

Codex はプロジェクトの説明を読み、必要なノードを確認します。ワークフローによっては調整が必要です。書き出し方が分からなければ、先に Codex に手順を聞いてください。

## アニメーションの作り方

キャラクター画像を添付し、Codex に次のように伝えます。

> comfyui-forge-video2dsprite を使い、このキャラクターが右を向いて、その場で走るループを作ってください。

既存の動画を渡して透過キャラクターアニメーションに変換することもできます。その場合、元動画の生成は不要です。

## 初回設定と納品

初回は完成サイズと再生時間を選べます。初期値は **128×128、1秒**です。fps は動作に応じて Codex が通常 **4～16 fps** の範囲で評価します。16 fps を超える場合は事前に確認があり、上限は24 fpsです。

元動画の解像度は **512×512（速度重視）、768×768（バランス、初期値）、1024×1024（品質重視）**から選べます。元動画は24 fps固定で、長さは完成品の再生時間の2～3倍を基準に設定されます。要求時間とフレーム整列後の実際の長さはいずれも15秒以内です。同じチャットでは確認済みの設定を再利用でき、生成前に完成品と元動画の設定概要が表示されます。

元動画では比較用に2～3回の完全な動作を目指しますが、合格する完全な候補が1つあれば十分です。完成品にはそのうち1つを使用します。標準ZIPには選択済みPNGフレーム、透過アニメーションシート、GIF、生成元動画のみを含め、JSONやログなどは作業フォルダーに残します。
